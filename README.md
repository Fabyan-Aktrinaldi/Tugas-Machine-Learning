# Prediksi Kemacetan Lalu Lintas

## Deskripsi
Project ini bertujuan untuk memprediksi volume lalu lintas berdasarkan data waktu dan kondisi lingkungan menggunakan Machine Learning.

## Dataset
Dataset diambil dari Kaggle: Metro Interstate Traffic Volume

Sumber: https://www.kaggle.com/datasets/damianogalassi/traffic-volume?select=Metro_Interstate_Traffic_Volume_train.csv


## Algoritma
- Decision Tree
- Gradient Boosting
- XGBoost

## Hasil
Model terbaik: XGBoost dengan R² ≈ 0.979
